# React + Vite Todo App

A responsive Todo application built using **React**, **Vite**, and styled using **Material-UI (MUI)**.

## Installation and Setup : 
1.**Clone the respository:**
```bash
    git clone [https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git)
    cd YOUR_REPOSITORY_NAME
```
2.**Install dependencies**:
```bash 
    npm install
```
3.**Install Material-UI and Icons packages:**
 ```bash
    npm install @mui/material @emotion/react @emotion/styled
    npm install @mui/icons-material
```
4.**Running the app:**
```bash
    npx vite
```
Open the local development URL provided in the terminal after running the app
